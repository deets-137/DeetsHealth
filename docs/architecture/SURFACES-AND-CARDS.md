# DeetsHealth — Surfaces and cards

## 1. Surfaces
Two, from DeetsMusic's three:
- **Midi** — one column of cards, the default window.
- **Max** — the wide grid (DeetsMusic's bento), for reading several cards side by side.

There is no Mini. The surface switch, card slots, card memory and card grow come from
DeetsMusic's engine (`../DeetsMusic/docs/architecture/SURFACES-AND-CARDS.md`,
`../DeetsMusic/docs/cards/`).

## 2. First cards
Proposed in [DESIGN.md](../DESIGN.md) §4: Labs, Medications, Allergies, Timeline.
Each card is a collection card over one normalized model. Which card comes first is open.
